# JewelBox Music Library

Source et documentation : <https://github.com/William-De71/Jewelbox-Music-Library>

```bash
cp .env.example .env   # renseigner MUSIC_DIR
docker compose up -d
```

- Interface : `http://<ip-hôte>:3002` (port changé : 3001 est pris par Projectory).
- Dans les Réglages, chemin de la bibliothèque : `/music`.
- Données : volume Docker `jewelbox_data`.
